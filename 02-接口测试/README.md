## 接口状态码必须搞懂这四个

| 码 | 含义 | 典型场景 |
|---|---|---|
| 200 | 成功 | 正常返回 |
| 401 | 未认证 | 没带 token |
| 403 | 无权限 | 带了 token 但权限不够 |
| 500 | 服务端错误 | 后端崩了 |

## 练习目标
