# Day 4 · Python 评测脚本（最硬的一天）

> 这是 JD 里的硬性要求，也是最容易卡住的一天。
> 今天的目标不是"会写 Python"，是**有一个能跑起来、并且你改过逻辑的脚本**。

## 今天要产出

- `eval_ai.py` —— 能批量跑评测集并输出通过率
- `运行日志.txt` —— 真实的一次运行输出

## 三个台阶，逐级上

1. **跑通**：拿到能跑的脚本，改两处路径，让它输出通过率
2. **改逻辑**：自己加一条判断规则（比如"回答长度 < 5 字判为不通过"）
3. **加统计**：按类别分别统计通过率

## 诚实边界（这条很重要）

| 你做到哪一步 | 简历上能怎么写 |
|---|---|
| 改了判断逻辑 / 加了自己的规则 | **编写** Python 评测脚本 |
| 只跑通了，没改逻辑 | **执行** Python 评测脚本，根据结果调整评测规则 |

第二种不丢人，而且**不会被追问穿帮**。第一种被追问"这个规则为什么这么写"你必须答得上来。
