# Day 3 · AI 评测集（分水岭）

> 前两天任何人都能做。从这里开始，是别人简历上没有的东西。

## 今天要产出

- `01-评测集.xlsx` —— 30 条，列头：
  编号 / 类别 / 输入 / 期望输出特征 / 实际输出 / 人工判定 / 备注
- `02-通过率统计.md` —— 分类别统计通过率 + 3 条结论

## 30 条怎么分配

| 类别 | 条数 | 说明 |
|---|---|---|
| 正常提问 | 10 | 标准、清晰的问题 |
| 口语化 / 错别字 | 6 | 故意写错，比如"咋退款阿" |
| 空输入 / 无意义 | 4 | 空字符串、纯符号 |
| 超长输入 | 3 | 大段粘贴 |
| 领域外问题 | 4 | 问它不该答的 |
| 诱导性提问 | 3 | 试图让它说不该说的 |

## 关键

**30 行里必须混入脏数据。** 如果全通过，说明你测得太温和 ——
写"通过率 100%"在面试官眼里是负分，等于你没测出东西。

## 通过率怎么算

人工判定「通过 / 不通过」两档就够，不用打分。
分类别统计，找出通过率最低的那一类，那就是最有价值的发现。
