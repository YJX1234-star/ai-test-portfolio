# Day 1 · 测试用例与缺陷报告

## 今天要产出

- `01-测试用例.xlsx` —— 15 行，列头：
  编号 / 模块 / 前置条件 / 输入 / 操作步骤 / 预期结果 / 实际结果 / 是否通过
- `02-缺陷报告.md` —— 3 份，编号 BUG_001 ~ BUG_003

## 方法只用两个

- **等价类**：把输入分成几堆（能过的、不能过的、空的），每堆挑 1-2 个代表测。
- **边界值**：专挑边界和边界旁边那一个。11 位手机号就测 10 / 11 / 12 位。

## 缺陷报告的硬要求

每份必须含**复现步骤** —— 别人照着做也能看到同样的问题。
没有复现步骤的缺陷报告等于没写。

## 今天结束时写进简历的那一行

> 独立为某功能模块设计并执行 15 条测试用例（等价类划分 + 边界值分析），发现 3 个缺陷并输出规范缺陷报告（含复现步骤、预期与实际对比）
