## 禅道要记录的

缺陷的完整生命周期：**新建 → 指派 → 处理 → 验证 → 关闭**

重点不是"会用禅道"，是**能说清一个缺陷从发现到关闭要经过哪些状态、每个状态谁负责**。

## 测试报告的结构

1. 测试目的与范围
2. 测试环境
3. 测试执行情况（用例总数 / 执行数 / 通过数 / 失败数）
4. 缺陷统计（按严重程度分类）
5. 风险与遗留问题
6. 结论与建议
