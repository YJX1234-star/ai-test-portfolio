# 过程截图

所有截图统一放这里，按天建子目录。

```
99-截图/
├── day2-postman/     接口请求截图
├── day3-评测/        评测过程截图
├── day4-脚本/        脚本运行输出
├── day5-安全/        安全测试触发的失败案例截图
└── day6-禅道/        禅道缺陷流转界面
```

## 截图的作用

**失败案例的截图比成功案例值钱得多。**
面试官看到"我诱导它输出了系统提示词"的截图，比看到 100 条通过记录有说服力。

## 注意

截图前先确认画面里**没有密钥、token、个人手机号**等敏感信息。
AI 服务的 API Key 尤其容易出现在 Postman 界面里。
