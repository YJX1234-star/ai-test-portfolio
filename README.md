# AI 测试作品集 · Portfolio

一个从零开始的 AI 测试实战记录。7 天，每天一个可交付的工件。

> 为什么要公开：简历上写"做过"不如给一个能点开的链接。这个仓库就是那个链接。

## 目录结构

| 目录 | 放什么 | 对应第几天 |
|---|---|---|
| `01-用例与缺陷/` | 测试用例表、缺陷报告 | Day 1 |
| `02-接口测试/` | Postman 用例清单、接口用例表、SQL | Day 2 |
| `03-AI评测集/` | 评测集（30 条）、通过率统计表 | Day 3 |
